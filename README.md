# MLOps/Deployment-Demo: Del Notebook a Producción

Este repositorio contiene un pipeline reproducible e interactivo de **MLOps** para el entrenamiento, empaquetado, servicio y monitoreo de un modelo de Aprendizaje Automático.

El objetivo principal es demostrar las buenas prácticas para llevar un modelo desde la etapa de experimentación hasta un entorno de producción controlado.
